# 🍪 Cookie Clicker Bot (YOLOv8 + ONNX)

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![YOLOv8](https://img.shields.io/badge/YOLOv8-Ultralytics-yellow)](https://github.com/ultralytics/ultralytics)
[![ONNX](https://img.shields.io/badge/ONNX-Runtime-green)](https://onnxruntime.ai/)

Умный бот для автоматизации игры Cookie Clicker (или её аналогов). Бот использует нейросеть **YOLOv8**, экспортированную в формат **ONNX**, для распознавания объектов на экране в реальном времени и выполнения соответствующих действий (клики по печеньке, сбор бонусов, закрытие рекламы).

## 🚀 Возможности

*   **Распознавание объектов**: Использует обученную модель YOLOv8 для поиска игровых элементов на экране.
*   **Умная логика**: Приоритет отдается закрытию рекламы и сбору улучшений, чтобы не пропустить важные события.
*   **Высокая скорость**: Благодаря формату ONNX и оптимизированному препроцессингу работает быстро даже на CPU.
*   **Управление с клавиатуры**: Запуск и остановка бота осуществляется нажатием **ПРОБЕЛА** (не нужно переключать окна).
*   **Аварийная остановка**: Если увести мышь в левый верхний угол экрана, бот мгновенно остановится (FailSafe).

🧠 Как это работает
Захват экрана: Бот делает скриншот экрана с помощью pyautogui.

Препроцессинг: Изображение ресайзится до 640x640, конвертируется в RGB и нормализуется.

Инференс: Модель ONNX предсказывает координаты и классы объектов.

Постпроцессинг: Применяется фильтр по уверенности (Confidence Threshold) и NMS (Non-Maximum Suppression), чтобы убрать дубликаты рамок.

Действие: На основе найденных объектов (печенька, улучшение, реклама) выполняются клики. Логика приоритетов встроена в функцию find_and_click().

📝 Обучение своей модели (Опционально)
Если вы хотите обучить модель под свою игру, вам понадобится:

Собрать скриншоты игры.

Разметить их в X-AnyLabeling (или LabelImg).

Экспортировать в формат YOLO (.txt).

Обучить модель в Google Colab:

from ultralytics import YOLO
model = YOLO('yolov8n.pt')
model.train(data='data.yaml', epochs=100, imgsz=640, batch=16)
Экспортировать модель в ONNX:

python
model.export(format='onnx')
⚠️ Важные замечания
Разрешение экрана: Бот написан с расчетом на стандартное разрешение. Если игра запущена в окне или на нестандартном разрешении, координаты могут сбиваться. При необходимости отредактируйте функцию postprocess.

Права администратора: На некоторых системах (особенно Windows) библиотека pynput (для перехвата пробела) может требовать запуска терминала от имени администратора.

Античит: Используйте бота на свой страх и риск. В многопользовательских играх за использование автоматических скриптов могут выдать бан.
